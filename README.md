# NEONRUSH — Android Game

A free, offline 3D futuristic microbus driving game built with **Godot 4.3**.

## Download for Android

**[Download the latest APK from GitHub Releases](https://github.com/Bushra-AI-Agent-prog/NEONRUSH/releases/latest)**

After downloading, open the APK on your Android phone and allow installation from that source if Android asks. This is a direct-install test build; test it on your device before wider distribution.

## Game features

- Procedurally generated neon night city
- Microbus driving physics, traffic AI and multiple cameras
- Passenger pickup/drop-off missions, checkpoints, fares and XP
- Garage with vehicle customisation and upgrades
- Weather cycle, rain and fog
- Touchscreen controls, minimap, route guidance and save system
- Offline gameplay with no ads or internet permission
