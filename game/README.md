# NEON BUS - Futuristic Microbus Taxi (Android)

A free, offline 3D driving game. You drive a neon-lit futuristic microbus through a procedurally
generated night city (left-hand traffic), pick up passengers, race checkpoints, earn money and XP,
and customise/upgrade your bus in the garage.

Built with **Godot 4.3** (MIT) and GDScript. **Every mesh, texture, shader, sound and music loop is
generated by code** - there are no third-party asset files, no internet permission, no ads, no paid
services. Total game data is ~110 KB.

## Features
- Procedural 8x8-block city: shader-lit skyscrapers, neon signs, street lamps, parks, skyline, boundary walls
- Arcade-tuned microbus physics (suspension, steering, brakes, handbrake, ION boost, flip/fall recovery)
- 3 cameras (chase / hood / far), speed FOV, crash shake
- Touch HUD: speedometer, boost bar, rotating minimap with route line, direction arrow with distance
- Traffic AI on road lanes (cars, vans, trucks) that slow for obstacles and stop when bumped
- Missions: Standard / Express / VIP jobs, checkpoints (+time, +cash), passenger comfort, fare, XP, levels
- Garage: 8 paints, 6 neon colours, 4 body kits, 5 upgrade lines x 5 levels (level-gated, bought with fare money)
- Weather cycle: clear night, neon rain (wet reflective roads), fog
- Main menu, pause menu, settings (volume, graphics Low/Med/High, steering sensitivity, left-handed layout, FPS counter), JSON save
- Procedural audio: engine, horn, crash, UI, rain, synthwave music

## Controls
Touch: on-screen buttons (< > steer, GAS, BRAKE, HB handbrake, ION boost, CAM, RST reset, HORN, II pause).
Keyboard (desktop testing): W/S, A/D, Space, Shift, C, R, H, Esc.

## Get the APK (zero cost, no PC build needed)
1. Create a free GitHub account and a **new empty public repository** (e.g. `neon-bus`).
2. Upload this project's contents (including the hidden `.github` folder) to the repo's `main` branch.
   - Easiest: on the repo page choose **Add file > Upload files**, drag in everything from the unzipped folder, commit.
   - Or with git: `git remote add origin https://github.com/<you>/neon-bus.git && git push -u origin HEAD:main`
3. Open the **Actions** tab. The *Build Android APK* workflow starts automatically (about 5-10 minutes).
4. When it is green, open the run and download the artifact **NeonBus-debug-apk**, or open the
   **Releases** page and download `NeonBus-debug.apk` from the "latest" release.
5. Copy the APK to your Android phone, allow "Install unknown apps", and install it.

The workflow installs JDK 17, the Android SDK, Godot 4.3 and its export templates, creates a throw-away
debug keystore (no secrets are stored anywhere), runs the automated tests, exports the APK, verifies it
(manifest, ARM libraries, signature, package name) and uploads it. GitHub Actions is free for public repos.

## Cars and graphics (session 2)
- 7 vehicles: the microbus plus 6 original car designs (sport coupe, muscle GT, performance coupe, luxury sedan, GT racer, luxury SUV). Unlock in Garage > Cars.
- Original designs only: no real brand logos, no licensed liveries, no copyrighted characters.
- Settings > Time of day: Day / Golden hour / Night. Graphics quality Low/Medium/High controls shadows and effects.
- Honest limit: everything is generated in code (zero cost, offline), so it is realistic *lighting* (PBR, reflections, shadows), not photographic models. Real photoreal cars need real 3D model files.
